Konsep Sederhana Fitur Subscription Member (MVP)
1. Club Membuat Paket Membership

Setiap club bisa membuat paket membership seperti:

Paket Bulanan

Paket Tahunan

Di dalam paket itu hanya ada:

Nama paket

Harga

Lama masa aktif

Tidak perlu variasi rumit dulu. Cukup jelas: bayar sekian → aktif sekian hari.

2. Archer Mendaftar ke Paket

Ketika archer bergabung atau memperpanjang:

Admin memilih paket untuk archer

Sistem mencatat tanggal mulai

Sistem otomatis menghitung tanggal berakhir

Selama belum melewati tanggal berakhir → status Aktif
Jika sudah lewat → status Expired

Sederhana dan otomatis.

3. Pencatatan Pembayaran

Untuk versi awal, cukup:

Admin menandai apakah archer sudah bayar atau belum

Bisa mencatat metode pembayaran (cash / transfer)

Bisa melihat riwayat pembayaran archer

Tidak perlu payment gateway dulu.
Yang penting: tahu siapa yang sudah bayar.

4. Status Member yang Jelas

Setiap archer hanya punya 2 kondisi utama:

Active → boleh latihan / booking

Expired → tidak bisa akses fitur tertentu

Ini membuat membership terasa punya nilai dan aturan yang jelas.

5. Reminder Sederhana

Agar club tidak perlu cek manual:

Notifikasi 3 hari sebelum masa aktif habis

Notifikasi saat sudah expired

Tujuannya supaya:

Archer ingat untuk bayar

Club tidak perlu follow-up satu-satu

Inti Konsepnya

Sederhananya:

Archer bayar → aktif sekian hari → sistem otomatis mengatur masa aktif → kalau habis harus bayar lagi.

Tidak perlu diskon, tidak perlu cicilan, tidak perlu fitur kompleks dulu.

Yang penting:

Masa aktif jelas

Status jelas

Pembayaran tercatat

Akses bisa dikontrol
